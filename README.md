# albertopadovan.github.io — redirect shell

This repository previously hosted a personal website. That site has been retired
and its content now lives on the research group site:

**https://albertopadovan.github.io/apgroup/**

This repo is kept alive only to preserve the `albertopadovan.github.io` apex domain
and forward old URLs. Each page here is a small HTML stub that redirects to the
corresponding page on the group site:

| Old URL | Redirects to |
|---|---|
| `/`, `/index` | `/apgroup/` |
| `/publications` | `/apgroup/publications/` |
| `/projects` | `/apgroup/` |
| `/recent_news` | `/apgroup/allnews.html` |
| `/manuscripts/*.pdf` | (kept in place; also mirrored at `/apgroup/papers/`) |

The full original site is preserved in the `old-site` branch and the
`pre-redirect-archive` tag.
